Smart Learn

An Adaptive Web-Based Mobile Learning Platform for Neurodevelopmental Learning Disorders

Smart Learn supports children aged 6–8 with dyslexia, dysgraphia, dyscalculia, and working memory difficulties. The platform combines interactive learning games, adaptive difficulty levels, Sinhala voice instructions, and progress tracking to support children's learning development.
